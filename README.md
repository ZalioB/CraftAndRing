# Craft & Ring: Minecraft Tiered Progression & Barricades

**Craft & Ring** mashes up **Elden Ring** and **Minecraft: Java Edition** into a single offline adventure!

## Features
- **Tiered Minecraft Weapons:**
  - Wooden Sword & Pickaxe (Starting Limgrave gear)
  - Stone Sword & Pickaxe
  - Iron Sword
  - Diamond Sword & Pickaxe
  - Netherite Sword (Endgame boss material craft)
- **Enemy Drop Material System:**
  - Soldiers & Miners drop Wood Planks and Cobblestone.
  - Knights drop Iron Ingots.
  - Troll Bosses & Crucible Knights drop Diamonds.
  - Remembrance Bosses drop Netherite Scrap.
- **In-Game Crafting:**
  - Craft all tier weapons directly from the Crafting Kit at any Site of Grace.
- **Deployable Block Barricades:**
  - Consumable Dirt Barricades, Cobblestone Walls, and Obsidian Shield Walls deployable in real-time combat for tactical cover.

## Installation & Launch
- Handled automatically by **Melty** via **ModEngine2**.
- Launches Elden Ring offline with Easy Anti-Cheat disabled in **one click**.
